# 2048 Game

A simple and fun puzzle game for your browser.

## Features
- **Easy to Play**: Works with arrow keys, WASD, or touch swipes.
- **Undo Button**: Go back a move if you make a mistake.
- **High Score**: Saves your best score.
- **Modern Look**: Clean design with smooth animations.

## How to Play
1. Move the tiles in any direction.
2. When two tiles with the same number touch, they merge into one.
3. Keep merging tiles to get to the **2048** tile and win!
